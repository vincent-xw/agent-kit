Skill 系统

Skill 是可复用的操作流程。你可以用大白话描述想要做什么,LLM 结合可用工具生成一份系统提示词,保存后一键执行,还能根据历史执行记录自动优化。

快速开始

  1. 点击 header 的「Skills」按钮
  2. 点击「+ 用大白话新建 Skill」
  3. 输入描述,例如:

打开真实场景 Demo,用手机号 13800138000 密码 test123 登录,验证码填 123456,进入第一个订单,打开帮助中心,在 H5 页面用 e2e_user / pass1234 登录

  1. LLM 生成 skill 的名称、描述和提示词
  2. 检查并编辑提示词,确认后保存
  3. 点击「▶ 一键执行」

工作原理

Skill 本质上是一段 system prompt。执行时,BFF 把它替换默认的 free-form prompt 发给 LLM,LLM 据此调用工具完成任务。

每个 Skill 保存在 skills/<slug>/ 目录:

skills/login-and-check-h5/
├── skill.yaml    # 元数据(名称、描述、版本、工具列表)
├── prompt.md     # 系统提示词
└── runs/         # 执行记录
    ├── 1724xxx.json
    └── 1724yyy.json

Skill 管理

列表与详情

  • 「Skills」面板的「Skills」标签页列出所有已保存的 Skill
  • 点击卡片查看详情:提示词、版本、使用的工具、执行历史
  • 详情页有三个按钮:
    • ▶ 一键执行 — 开始运行
    • ⟳ 优化 Skill — 根据历史记录让 LLM 改进提示词
    • 删除 Skill — 不可恢复

历史记录

  • 「Skills」面板的「历史」标签页列出所有执行记录(跨 Skill,按时间倒序)
  • 每条记录显示状态(成功/失败/已停止)、时间、摘要
  • 点击跳转到对应 Skill 的详情

优化 Skill

Skill 详情页点「⟳ 优化 Skill」:

  1. BFF 读取该 Skill 的所有执行记录
  2. LLM 分析成功和失败模式
  3. 生成改进后的提示词和新版本号(如 1.0.0 → 1.1.0)
  4. 弹窗显示分析说明和新提示词,你确认后保存

优化后的提示词覆盖 prompt.md,版本号更新到 skill.yaml。旧版本不保留(git 可追溯)。

编写高质量的 Skill 描述

描述越具体,生成的提示词质量越高。好的描述包含:

  • 起点:从哪个页面/状态开始
  • 步骤:每一步做什么、输入什么数据
  • 预期结果:完成后应该看到什么
  • 异常处理:遇到错误怎么办

差的描述:

帮我登录一下

好的描述:

启动应用,用 13800138000 / test123 登录,验证码填 123456。如果提示网络错误就重试一次。登录成功后应该看到「我的」tab。

Skill 与自定义工具的区别

Skill Tool 插件
形态 Prompt 文本 可执行 JS/TS 代码
用途 教 Agent 完成特定流程 给 Agent 增加新能力
运行 作为 system prompt 发给 LLM 在 BFF 进程内执行
适合 标准化测试流程、操作步骤 调 API、查数据库、业务逻辑

两者可以配合使用——Skill 可以调用你写的自定义工具。详见 自定义工具。
